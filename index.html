What is a Derivative?

A derivative measures how a function changes with respect to its input. Geometrically, it represents the slope of the tangent line.

f'(x) = lim h→0 [f(x+h) − f(x)] / h
Example:
If f(x) = x², then:
f'(x) = 2x
